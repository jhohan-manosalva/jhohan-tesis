Diseña líneas de transmisión, paso a paso

Herramienta educativa para los cálculos mecánicos de líneas de alta tensión, conforme al RETIE y a estándares internacionales. Este manual te lleva de la instalación al reporte final, módulo por módulo.

34.5 – 500 kV ACSR · AAAC · AAC Ecuación de estado 4 hipótesis RETIE Distancias de seguridad Ampacity IEEE 738
Empezar por la instalación → Ver el flujo de trabajo

¿Qué calcula el software?

Ecuación de cambio de estado, flechas y longitud de conductor, cargas mecánicas (viento, peso, hielo), vano regulador y crítico, las cuatro hipótesis de diseño y la verificación de distancias mínimas de seguridad. Todo pensado como apoyo académico para el diseño de líneas de transmisión.

Antes de empezar

Requisitos e instalación

Necesitas Python 3.10 o superior, 4 GB de RAM (recomendado 8 GB) y un navegador actual (Chrome, Edge, Firefox o Safari). El programa se ejecuta en tu navegador de forma local.

1 · Verifica Python

$ python --version $ pip --version
▲

Al instalar Python en Windows, marca la casilla “Add Python to PATH”. Sin ella, los comandos anteriores no funcionarán.

2 · Entorno virtual e dependencias

# Situado en la carpeta calculos_mecanicos_at python -m venv venv venv\Scripts\activate # Windows # source venv/bin/activate # macOS / Linux pip install -r requirements.txt

3 · Ejecuta la aplicación

$ streamlit run app.py
●

Se abrirá automáticamente en http://localhost:8501. Si no abre solo, copia esa dirección en tu navegador.

01
Datos del conductor
Selecciona el cable y revisa sus propiedades
 ›
Objetivo: escoger el conductor que se usará en todo el diseño.
  1. Selecciona el tipo de conductor: ACSR, AAAC o AAC.
  2. Selecciona el calibre/código (p. ej. Hawk, Drake, Penguin).
  3. Revisa las propiedades: sección, diámetro, peso por km, carga de rotura, módulo de elasticidad y coeficiente de dilatación.
●

¿Tu conductor no está en la base de datos? Expande “Ingresar Conductor Personalizado”, completa todos los campos y pulsa “Usar Conductor Personalizado”.

02
Condiciones ambientales
Clima, altitud, temperaturas y viento del proyecto
 ›
Objetivo: configurar el entorno climático donde operará la línea.
  1. Selecciona la zona climática de Colombia.
  2. Ajusta la altitud específica del proyecto (msnm).
  3. Verifica las temperaturas: mínima (Hip. B), media (EDS) y máxima ambiente.
  4. Ajusta la velocidad de viento de diseño.
  5. Configura la temperatura de operación del conductor y el % EDS (típico 18%).
◆

Corrección por altitud: para tensiones > 57.5 kV y altitudes > 1000 msnm, el sistema aplica el factor automáticamente.

03
Cálculo mecánico
Tensiones, flechas y cargas para tus vanos
 ›
Objetivo: calcular tensiones, flechas y cargas del conductor.
  1. Configura los vanos: un solo vano, o varios separados por comas.
  2. Verifica el vano regulador calculado.
  3. Define los parámetros: temperatura inicial/final, incluir o no viento y método de solución (Cardano, Newton o Brent).
  4. Pulsa “Calcular”.

Fundamentos

Fundamentos teóricos

Las fórmulas clave detrás de los cálculos, por si necesitas justificar un resultado en tu informe.

Ecuación de cambio de estado

Forma cúbicaσ₂³ − σ₂² · A − B = 0
CoeficientesA = σ₁ − E·α·(t₂−t₁) + (E·a²·g₁²) / (24·σ₁²)   |   B = (E·a²·g₂²) / 24

Relaciona la tensión del conductor entre dos estados (temperatura y carga). σ = tensión unitaria (kg/mm²), E = módulo de elasticidad, α = coef. de dilatación, a = vano regulador, g = carga específica.

Flecha

Aproximación parabólica (f/a < 5%)f = (w · a²) / (8 · H)
Catenaria exactaf = c · [cosh(a / (2·c)) − 1]   con  c = H / w

Vano regulador

Cantón completoLr = √( Σ(Lᵢ³) / Σ(Lᵢ) )
▲

Regla del cantón: el vano máximo no debe superar 2.5 × el vano regulador.

Cargas mecánicas

Carga de vientop_v = (ρ · V² · Cd · d) / 2
Peso resultantew_r = √( w_c² + p_v² )

Ayuda

Solución de problemas

“La tensión calculada excede el límite”

Reduce la tensión EDS inicial, verifica que el vano no sea excesivo o considera un conductor de mayor sección.

“No se encontró solución física válida”

Revisa los parámetros de entrada: la combinación de temperatura y carga puede ser incompatible. Prueba con otro método de solución (Newton o Brent).

“El cantón no es válido”

El vano máximo supera 2.5 veces el regulador. Redistribuye las estructuras o divide el cantón.

“Distancia no cumple RETIE”

Aumenta la altura del soporte, reduce la flecha (subiendo la tensión EDS) o verifica que la flecha usada sea la de la Hipótesis D.

Dudas frecuentes

Preguntas frecuentes

¿Cuál método de solución debo usar?

Cardano es el más rápido y preciso para la mayoría de casos. Usa Newton o Brent solo si Cardano falla.

¿Por qué la tensión aumenta al bajar la temperatura?

El conductor se contrae térmicamente, lo que incrementa la tensión mecánica. Por eso la Hipótesis B (temperatura mínima) es crítica.

¿Cuándo debo considerar carga de hielo?

En Colombia, solo en páramos por encima de 3500 msnm donde puede haber formación de escarcha.

¿Qué valor de EDS debo usar?

Típicamente 15–20%. Un EDS menor reduce la fatiga por vibración eólica, pero aumenta la flecha.
